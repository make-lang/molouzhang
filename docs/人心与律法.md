# 人心与律法 · 设计稿

状态：第一步（记忆和人心，v0.21）、第二步（律法，v0.22）已经做了，第三步文字还没做。和草案不一样的地方记在最后一节。

## 一、要解决什么

到 v0.20 为止，几乎每个决定都是在算资源：粮食、材料、人手、化学品。游戏里已经有不少"该不该"的时刻——送走被咬的人还是截肢、拆掉别人想保住的楼、答应了求救信号又失约、一连五天只吃番薯——但它们的后果只是一两天赌气，过了就没了，玩家没有理由犹豫。

人心系统要让这些时刻留下痕迹，律法让玩家主动做"有效但伤人"的选择。按设计原则，先回答它让玩家在哪两件事之间纠结：**在"整个据点活下去"和"对得起眼前这个人"之间纠结。** 律法是前者的工具，人心是后者的代价。

和冰汽时代的区别（也是我们打算做得更好的地方）：

- 冰汽时代的人心是全城一个数。我们的人心落在每个人身上，同一条律法有人赞成、有人反对，你收了什么人决定了哪些律法推得动。
- 冰汽时代的不满经常说不清从哪来。我们每份不满都有具体的由头，而且看得到、会被人提起。
- 冰汽时代的法律树老玩家能背出最优路线。人心分到个人以后，最优路线随这一局的人员组成变。
- 冰汽时代人心一垮容易进死亡螺旋。我们要留回头路：人心低是"日子难过"，不是"这局完了"。
- 我们美术比不过，所以在文字上赢：故事是这一局自己长出来的，关于具体的人，前面发生的事后面会被提起。

## 二、记忆：人心的来源

每个住户身上记着几件对自己有分量的事（`v.mem`），这是整套系统的地基：人心从记忆算出来，文字从记忆里取细节。

一条记忆长这样：

```js
{ k: 'sentAway', who: 12, d: 37, w: -18, fade: 0 }
// k：哪类事；who：牵涉到的人（可选）；d：哪一天；w：对人心的影响；fade：每天淡掉多少（0 = 不会淡）
```

每人最多记 8 条，满了挤掉影响最小的那条。大部分记忆会慢慢淡掉；少数刻骨铭心的不会淡（亲友被送走、被你救回来）。

会留下记忆的事，先从游戏里已有的时刻挑：

| 事情 | 谁记得 | 影响 | 会不会淡 |
|---|---|---|---|
| 被咬后被送走 | 旧识（重）、在场的人（轻） | 旧识 -18，其他人 -4 | 旧识不淡 |
| 截肢保命 | 本人、旧识 | 本人 -6（但活着），旧识 +6 | 淡 |
| 牵挂兑现 | 本人 | +12 | 慢慢淡 |
| 牵挂到期没人管 | 本人 | -10 | 淡 |
| 想保住的楼被拆 | 本人 | -12（现在已经会结仇） | 淡 |
| 答应求救又失约 | 所有人 | -5 | 淡 |
| 救回了谁的家人 | 本人、被救的人 | +15 | 不淡 |
| 撑过尸潮 | 所有人 | +4 | 淡 |
| 有人死了 | 旧识（重）、其他人（轻） | -15 / -3 | 旧识慢慢淡 |
| 断粮那一晚 | 所有人 | -6 | 淡 |
| 签了一条律法 | 赞成的人、反对的人 | 见第四节 | 慢慢淡 |

## 三、人心怎么算、有什么用

每人的人心是 0–100，底数 50，加上身上所有记忆的影响，再加上眼前的处境：

- 吃得杂不杂（现在的吃腻机制并进来，不再单独赌气）；
- 床位挤不挤（超过床位的人人心往下掉）；
- 受伤、被咬的时候本人人心低一截；
- 旧识在不在（旧识都走了的人会孤单）。

界面上只分四档，不显示数字，但点开住户能看到原因（就是他身上的记忆）：

| 档位 | 范围 | 效果 |
|---|---|---|
| 振作 | 70 以上 | 偶尔多出一点力（干活结算时一成机会 +1）；投奔的人觉得这里有希望 |
| 平常 | 35–70 | 没有效果 |
| 低落 | 15–35 | 干活 -1；不肯接最危险的活（端巢、清理丧尸多的地块） |
| 崩溃 | 15 以下 | 每天有机会做出点事：半夜走掉、跟人打架、偷吃存粮。两个崩溃的旧识会一起闹 |

整个据点的气氛是大家人心的平均，影响投奔概率（替代现在只看存粮的 `arrivalChance` 一部分）和一部分早晨事件出现的机会。

防止死亡螺旋的几条：崩溃的效果是"有机会"而不是必然；拉人心的手段要多而且便宜（办一顿好饭、兑现一个牵挂、休息一天、撑过尸潮）；坏记忆大多会淡。人心低该是让你改变打法的压力，而不是读档的理由。

## 四、立场：同一件事，各人反应不同

这是比冰汽时代多出来的一层。每个人有两三个立场标签，由职业和特质决定，再随机加一点：

| 标签 | 谁多半有 | 在意什么 |
|---|---|---|
| 人情 | 护理师、人缘好、懂护理 | 不能丢下伤员、病人和被咬的人 |
| 规矩 | 退休警察、保全、里长 | 安全和秩序，愿意为大家牺牲个人 |
| 公平 | 大学生、国中老师 | 谁干得多谁吃得多不对，人人平等 |
| 实在 | 菜贩、夜市摊贩、外送员 | 多劳多得，别管太多 |
| 念旧 | 里长、名字带"老"的 | 老规矩、入土为安、别拆老房子 |
| 拼命 | 健身教练、冲动、大胃王 | 吃饱、能打、往外冲 |

律法签下去的时候，赞成的人留下一条好记忆，反对的人留下一条坏记忆；之后每次律法"生效"的具体时刻（比如真的把一个被咬的人送走了），反对的人会再记一笔。

## 五、律法

律法两两成对、互相排斥：同一时间只能有其中一条生效。这跟科技相反（科技不互斥），因为对立的立场本来就不能同时成立。

律法可以废除，但代价很重，就像现实里领导朝令夕改会失去人心一样（用户定的）：

- 废除要占掉一次签律法的机会（那个时机只能废、不能再签新的）。
- 当初赞成的人记一笔"说话不算数"（-12，慢慢淡）；其他人也记一笔轻的（-4）。
- 据点多一点"朝令夕改"（`s.flip`，每废一次 +1，不会消失）：之后每签一条律法，反对的人那笔坏记忆加重 25% × `flip`。废得越多，以后推什么都越难。
- 废掉一条以后马上签它的对立面（从配给改成按劳分配）可以，但要等下一个时机，而且两边的人都会记得你翻过一次。

签律法的时机沿用现在抽楼规卡的时机：每次换季第一天、尸潮频繁的城市撑过尸潮之后，可以从律法表里挑一条签、废掉一条，或者什么都不做。不再是三张随机卡选一，而是整张律法表摆在那里。

头一批六对：

| 方面 | 律法 A | 律法 B |
|---|---|---|
| 吃饭 | **统一配给**：每人吃的少两成五。实在、拼命的人反对；每次断粮前的那几天大家记一笔 | **按劳分配**：出门干活的人人心 +，留守和伤员人心 -；干活的人效率 +1 |
| 咬伤 | **被咬就送走**：不会再有尸变事件，也不会有人在制服尸变的人时受伤。每送走一个，人情、旧识记重重一笔 | **隔离间**：占一张床；被咬的人多拖两晚；尸变时不会伤到别人。人情赞成，规矩觉得冒险 |
| 干活 | **加班令**：每 7 天里有一天所有干活结算 +1；伤员恢复慢 1 天；所有人每周记一笔累 | **休息日**：每 7 天全员休一天（只守夜不干活），那天人心大涨 |
| 外人 | **来者不拒**：投奔的人多一半，但偶尔混进带伤的、被咬的、有过节的 | **先查后收**：投奔的人少三成，但不会有被咬的混进来；规矩赞成，人情反对 |
| 死者 | **遗物充公**：死去和离开的人身上的东西直接进仓库，另外拆出 2 份材料。念旧、旧识记一笔 | **入土为安**：要 2 木料、一个人半天办丧事；旧识的坏记忆淡得快一倍；念旧赞成 |
| 守夜 | **巡逻队**：每块地盘夜里防御 +1；被派巡逻的人第二天人心 -；规矩赞成 | **自治会**：吵架、过节、营地交涉的事件多一个"大家商量"的选项，结果更好；公平赞成 |

## 六、文字

规矩只有几条：具体（写名字、东西、地点，不写"大家很难过"）；克制（短，不煽情，留白）；有口气（退休警察和大学生说话不一样）；前后呼应（前面发生的事，后面要被提起）。

每类时刻准备好几种写法，并且从记忆里取细节拼进去，避免同一句看到第五次。示范：

> 现在："阿玉心情不好，明天不想干活。"
>
> 之后："阿玉把志明的安全帽挂在门口，一整天没出门。"

签"被咬就送走"时，如果有人记得被送走的旧识：

> 阿玉看了你一眼，什么也没说。她记得志明是怎么走的。

人心振作时的早晨：

> 老陈一早就在顶楼哼歌，说撑过这次尸潮，下个月要在公园种一排丝瓜。

两个崩溃的旧识一起闹：

> 半夜储藏室的锁被撬开了。美华和阿杰背着两袋米站在楼梯口，看见你，谁也没先开口。（选项：让他们走 / 把米留下，人可以走 / 坐下来谈）

## 七、界面

- 住户卡片上加一个小图标表示人心档位，悬停写一句原因（最重的那条记忆）。
- 点开住户：列出他记着的事（就是记忆，写成一句话），和他的立场标签。
- 新增"律法"分页（或并进现在的楼规按钮）：整张律法表，成对排列，标出签了哪条、哪条再也签不了、签了以后谁会高兴谁会不满（按现在的住户逐个列出）。
- 顶栏加一个据点气氛。

## 八、怎么测

脚本要会签律法（按自己的打法挑：会规划多半签统一配给、隔离间、休息日），要会管人心（低落的人别派去端巢）。要看的数字：

- 胜率仍然守住底线：会规划 60–70%、先打巢不低于 25%；
- 每局有多少人因为崩溃离开，跟断粮离开的人数对比；
- 不签任何律法的胜率，确认律法有用但不是必签；
- 每对律法里两边被选的比例，一边倒说明有一条太强。

人心系统里最重要的部分——玩家会不会真的犹豫、文字有没有分量——脚本测不出来，要人来玩。

## 九、分几步做

1. **记忆和人心**（v0.21）：加 `v.mem`、人心计算、四档效果，把现在的赌气、吃腻、牵挂、拆楼结仇、送走被咬的人都接进来。先不加律法，楼规卡不动。界面加人心图标和住户记忆。
2. **律法**（v0.22）：立场标签、六对律法、签律法的时机，楼规卡按上表拆掉或转成科技。存档迁移：已经选了的楼规卡，转成对应的律法或科技。
3. **文字**（v0.23）：按记忆拼的多种写法、崩溃事件、振作时的小段落，整体过一遍口气。

1. 头一批六对律法里，有没有你特别想要或者觉得不对味的？

## 十一、v0.22 实现时改动的地方

- 签律法不弹三选一的对话框：换季第一天（尸潮频繁的城市撑过尸潮）给一次签字机会（`s.lawSlot`，最多攒 2 次），楼长在顶栏“律法”按钮里看整张表，什么时候签都行。签、废之前先确认，确认框里列出谁会高兴、谁会不满。
- 第七对律法叫“心愿”：说到做到 / 各顾各。
- “守望相助”没有并进按劳分配的对立面（统一配给本来就是它的对立面），改成并进自治会：旧识一起干活 +2。
- 被咬就送走：被咬当晚就送走（等不到用急救包），换来大家出门更小心（搜刮受伤率 ×0.9）。草案里它的好处只有“不会尸变伤人”，跟现在的默认差不多，没有取舍。
- 先查后收：草案里的“不会混进被咬的”只是来者不拒的反面，本身没好处，改成查过的人最强的技能 +1。
- 来者不拒：新来的人有四分之一机会带伤、被咬或者跟楼里的人有过节。
- 立场按职业、特质、名字给，不够两个按 id 和名字哈希补，不消耗随机数（同种子地图不变）。
- 立场的“生效时刻”只做了几处：照规矩送走人时人情的人记一笔、遗物充公时念旧的人和旧识记一笔、下葬时念旧的人记一笔、加班日累、休息日睡饱、巡夜的人累。
